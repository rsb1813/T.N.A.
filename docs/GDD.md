# T.N.A. 게임 디자인 문서 (GDD)

> 장르: 3인칭/1인칭 제트 전투기 액션 슈팅 (싱글플레이 캠페인 중심)
> 플랫폼: 웹 (three.js + TypeScript), 키보드+마우스 / 게임패드
> 세계관: `docs/world.md` (신냉전 대체역사, 2000년)
> 이 문서는 디자인 기준이다. 구현 규칙은 `docs/architecture.md`.

## 1. 핵심 방향

1. **에이스컴뱃의 손맛 + 워썬더의 무게감.** 조작은 쉽고 화끈하게, 하지만 에너지·무장·센서는 진짜처럼 작동한다.
2. **실제 무장 체계.** "미사일 80발" 같은 추상화 대신 AIM-120D, AIM-9X Block II, GBU-31 처럼 실제 제식 무장을 실제 하드포인트에 단다. 무게와 항력은 비행 성능에 반영된다.
3. **기체 커스터마이징이 전술을 바꾼다.** 날개 키트, 엔진, 레이더, IRST, RWR, MAW, 전자전, 대응체계, 데이터링크, HMD 를 바꾸면 체감 성능과 전투 방식이 달라진다. (예: MAW 가 없으면 적외선 미사일이 날아와도 경고가 뜨지 않는다.)
4. **세 세력의 전쟁.** NATO(플레이어) / 바르샤바 조약기구 / 팍스 임페리알리스 + 변수 WON. 적마다 교리와 장비가 확실히 다르다.
5. **원작 표절 금지.** 에이스컴뱃의 장르적 문법(HUD 스타일, 무전 연출, 미션 구조, 에이스 부대)은 쓰되 고유명사·설정·대사·초병기 디자인은 전부 새로 만든다.

## 2. 난이도 위치: 에이스컴뱃과 워썬더 사이

| 항목 | 에이스컴뱃 | **T.N.A.** | 워썬더 RB |
|---|---|---|---|
| 조종 | 직접 각속도 조종 | 직접 각속도 조종(기본) + 마우스 에임(선택) | 마우스 에임/풀리얼 |
| 에너지 | 거의 없음 | **선회하면 속도가 깎이고, 고도는 에너지 저장고** | 완전 시뮬 |
| 실속 | 거의 없음 | FBW 받음각 제한, 저속에서 기수가 처짐 | 스핀까지 |
| G 한계 | 없음 | 기체별 G 한계, 무거운 무장 장착 시 감소 | 날개 파손 |
| 미사일 수 | 수십 발 | **실제 장착량 (F-15EX 공대공 10발 등)** + 보급 구역 재무장 | 실제 |
| 미사일 성능 | 짧은 사거리, 쉽게 맞음 | 추력·항력 기반 에너지 비행, 고도·속도·종횡비에 따라 사거리 변화 | 실제 |
| 센서 | 레이더 미니맵 | 레이더 탐지거리·RCS·재밍·RWR·MAW 가 실제로 작동, 표시는 에이스컴뱃식 | 실제 |
| 피해 | HP | HP + 부위 피해(엔진/날개/조종면) | 부위 피해 |

난이도 옵션: `normal`(보조 기능 켜짐) / `hard` / `ace`(받는 피해↑, 적 명중↑, 점수 배율↑). 보조 기능(FBW 리미터, 기관포 리드, 위협 화살표)은 개별로 끌 수 있다.

## 3. 비행 모델

- 점질량 + 자세 모델. 조종 입력은 **요구 각속도**(피치/롤/요)이고, FBW 가 받음각·G 한계 안에서 따라간다.
- 힘: 추력(고도·속도 감소, 스풀 지연, 애프터버너), 항력(CD0 + 유도항력 k·CL² + 천음속 조파항력 + 외부무장 CdA + 에어브레이크), 양력(CLα·α, CLmax 에서 실속), 중력.
- 결과적으로: 지속선회율/순간선회율이 기체마다 다르고, 무장을 많이 달면 둔해지며, 급선회를 계속하면 속도를 잃는다. 고도를 속도로 바꾸는 붐앤줌이 유효하다.
- 연료: 엔진별 연료소모율. 애프터버너는 연료를 크게 먹는다. 외부탱크 연료부터 소모. 연료가 떨어지면 엔진 정지.
- 가변익(F-14EX): 속도에 따라 자동 후퇴각 (20°~68°). 저속 양력↑ / 고속 항력↓.
- 보조(normal): 저고도 경고 + 자동 회피 없음, 실속 방지 리미터, 과G 방지.
- 기체 손상: 엔진 손상 → 추력 감소, 날개 손상 → 양력 감소·롤 쏠림, 조종 손상 → 각속도 감소.

## 4. 무장과 센서

### 4.1 공대공 미사일 (실제 거동)
- 로켓 모터 (부스트/서스테인) → 소진 후 항력으로 감속하는 활공. **고고도·고속에서 쏘면 멀리 간다.**
- 비례항법 유도, 최대 기동 G 는 속도·공기밀도에 비례해 줄어든다 → 사거리 끝에서 쏜 미사일은 선회하면 피할 수 있다.
- 유도 방식별 특징
  - **능동 레이더 (AIM-120D, R-77, Meteor)**: 발사 후 데이터링크 중간유도, 표적 근처(pitbull)에서 자체 시커 작동 → 이때 RWR 경보. 데이터링크 지원 동안은 발사 기체가 표적을 레이더로 추적해야 정확.
  - **반능동 (AIM-7, R-27R)**: 명중까지 발사 기체가 STT 락 유지해야 함.
  - **적외선 (AIM-9X, R-73, ASRAAM)**: 발사 후 망각, RWR 경보 없음 → **MAW 가 있어야만 경고**. 플레어로 기만. 신형일수록 대응책 저항(CCM) 높음. HMD 가 있으면 고 off-boresight 발사.
  - **장거리 (AIM-54C, R-33, R-37)**: 거대한 사거리, 낮은 기동성 → 대형기/폭격기 요격용.
- 회피: 빔 기동(노칭: 표적이 레이더 시선과 수직이 되면 도플러 레이더가 놓침), 채프(레이더), 플레어(적외선), 재머(락 거리 감소), 에너지 고갈 유도(드래그).
- 발사가능영역(DLZ): HUD 에 Rmax / Rne 표시. 에이스컴뱃식 락 박스 + 락 진행.

### 4.2 공대지
- GPS 폭탄(GBU-31/38/39): 지점 표적, 전천후, 투하 후 망각. 고고도·고속 투하 시 사거리↑. 이동표적엔 약함.
- 레이저 유도(GBU-12/24): 표적 포드(Sniper/LITENING)가 있어야 자체 조사 가능, 이동 표적 가능. 표적 지정 유지 필요.
- AGM-65 Maverick(EO/IR): 발사 후 망각, 이동 표적.
- AGM-88E AARGM: 방사 중인 레이더(SAM)로 날아감. 레이더가 꺼져도 마지막 위치 + 자체 밀리미터파 시커.
- AGM-158 JASSM / AGM-84 Harpoon: 원거리 순항, 저고도 비행.
- 무유도 폭탄(Mk 82/84): CCIP 조준점 표시.
- 전술핵 (B61 계열): 세계관상 제3국에서는 "합법". **미션이 지정할 때만** 장착 가능. 거대한 폭발/섬광/EMP 연출.

### 4.3 기관포
- M61A2 20mm (6000rpm). 탄수 제한(실제 값). 예광탄. 리드 조준점(보조 켜짐 시).

### 4.4 센서·전자전
- **레이더**: 탐지거리 ∝ RCS^(1/4). AESA 는 다중 표적 추적·동시 유도·LPI. 스텔스기(F-22D, 팍스 실험기)는 가까이 와야 보인다. 지상 모드(SAR) 가 있으면 지상 표적 원거리 탐지.
- **IRST**: 수동 탐지(상대 RWR 에 안 잡힘). 애프터버너 쓰는 적은 멀리서 보임. 스텔스기 대응 수단.
- **RWR**: 탐색/추적/발사 경보, 방사원 방향. 식별 능력·LPI 탐지력은 장비별 차이.
- **MAW**: 모터 화염을 탐지해 모든 미사일 경고. 없으면 적외선 미사일은 경고 없이 날아온다.
- **전자전(재머)**: 적 레이더의 락 거리 단축. 켜면 상대 RWR 에는 재밍 신호가 보인다(존재 노출). 견인 디코이는 레이더 미사일을 일정 확률로 유인.
- **데이터링크**: AWACS/윙맨 트랙 공유, 협동 교전(아군 트랙으로 원거리 발사).
- **HMD**: 고 off-boresight IR 미사일 발사, 시선 방향 표적 지정.

## 7. 적 세력 (교리 반영)

- **바르샤바 조약기구** (물량, 중장갑, 미사일 포화): Su-27S/Su-30/Su-35S(J-11 포함), MiG-29, MiG-31(장거리 요격), Su-47(실험), Tu-22M3(핵 폭격기), A-50(AWACS). R-77/R-73/R-27/R-33/R-37. S-300(SA-10), Buk(SA-11), Tor(SA-15), ZSU-23-4. Slava 순양함.
- **팍스 임페리알리스** (소수 정예, 비싼 실험 무기): Eurofighter Typhoon, Tornado ADV/IDS/ECR, 실험 스텔스 전투기(가칭 "XF-1 Lampyris", 독일 Lampyridae 계열 연구 기반 가상기), Su-27 파생형(러시아 제국). Meteor(램제트), ASRAAM, IRIS-T, Storm Shadow, ALARM. Rapier, Type 42/23 함정. **명명된 에이스 편대**가 반복 등장. MOUK 운반 수단이 최종 위협.
- **WON** (저렴·개조 장비, 게릴라): Mirage F1, MiG-21 개량형, Cheetah. SA-2, 기관포 트럭, 견인 대공포.

적 AI 숙련도: rookie / regular / veteran / ace. 에이스는 노칭·드래그·플레어 타이밍·에너지 관리를 한다.

## 8. 캠페인 구조

- 싱글 캠페인, 플레이어 = NATO **제1 연합 선봉 비행단 (1st Allied Vanguard Wing)** 소속 정예 편대의 1번기.
- 4막, 16~20 미션 (`docs/story.md` 에 전체 줄거리). 첫 빌드에서는 튜토리얼 + 1막 미션 3개를 플레이 가능하게 만든다.
- 미션 흐름: 브리핑 → 격납고(기체·무장 선택) → 출격(공중 시작) → 결과(점수/랭크/크레딧).
- 미션 유형: 제공권 장악, 지상 타격, SEAD, 대함, 요격(폭격기 저지), 호위, 방어, 정밀 타격(시간 제한), 에이스 결투, 초병기 공략.
- 재무장: 일부 미션은 보급 구역(아군 기지 상공/공중급유기)에 진입하면 재무장·재급유 (에이스컴뱃식 편의 + 실제 장착량 유지).
- 무전 연출: AWACS·윙맨·적 에이스·사령부의 무전 자막. 전투 상황(발사, 격추, 피격, 미사일 경보)에 반응하는 윙맨 대사.
- 랭크: S/A/B/C (시간, 점수, 피해, 명중률).

## 9. HUD (에이스컴뱃식 표현)

속도/고도 테이프, 방위, 피치 래더, 비행경로 표시기, G·마하·AoA, 스로틀/AB, 연료, 무장 목록(남은 수), 표적 박스(거리·기종·TGT 표시), 락 박스와 락 톤, DLZ 바, 미사일 경보(방향 화살표, MAW 있으면 남은 시간), 레이더 미니맵, 화면 밖 표적 화살표, 피해율, 목표/시간/점수, 무전 자막.
